# ha-xfinity-dvr
Control your xFinity X1 DVR through the network cloud API - no more IR needed.

Add custom repo to HACs: https://github.com/davedave1234/ha-xfinity-dvr/
Download the APP.
Install the integration and generate the token in the initial install.

To find the Easy Pair app on your Xfinity X1 DVR, you have two simple options using your physical Xfinity remote:
Option 1: Voice Command (Fastest)
   Press and hold the Microphone button on your Xfinity remote.
   Say "Easy Pair".
   The Easy Pair app will launch immediately on your TV.
Option 2: Manual Navigation
   Press the Xfinity button on your remote to open the main menu.
   Use the arrow keys to navigate to Apps and press OK.
   Scroll down to the Xfinity row.
   Select the Easy Pair app tile and press OK.
